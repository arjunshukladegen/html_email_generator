# Setup & Usage

### Step 1: Clone the repo in your desired directory.
```
$ git clone git@github.com:arjunshukladegen/html_email_generator.git
```

### Step 2: Run ruby command with '~/' in home directory to test the CLI
```
$ ruby ~/"PATH_TO_REPO"/lib/email_tool.rb
```

### Step 3: If it runs, set a global alias in '.zshrc'
```
Step 1: Make sure you are in home directory.
$ cd

Step 2: Open up .zshrc config file.
$ nano .zshrc

Step 3: Copy the following command.
$ pixelmail="ruby ~/"PATH_TO_REPO"/lib/email_tool.rb"

Step 4: Find an empty line in .zshrc config to write your alias.

Step 5: Paste alias into .zshrc.

Step 6: Save, exit, and confirm.
- [CTRL] + [O] (save)
- [CTRL] + [X] 
- [ENTER]

Step 7: $ source .zshrc

Step 8: $ pixelmail
```

## If 'pixelmail' now runs the program, you are fully set up and ready to go!
